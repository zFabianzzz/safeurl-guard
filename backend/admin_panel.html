Cómo funciona la blacklist
Flujo de aplicación de las reglas
1

Selecciona el alcance. Una regla global aplica a todos los dispositivos, mientras una regla específica solo afecta al equipo elegido.

2

Define el patrón. La extensión consulta la blacklist antes de ejecutar el análisis del modelo.

3

Bloqueo inmediato. Cuando la URL contiene el patrón, se muestra la pantalla de bloqueo sin opción de continuar.
